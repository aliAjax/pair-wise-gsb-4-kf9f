# License Lens

纯前端的开源依赖许可证兼容性分析工具，供法务初审依赖清单使用。数据只保存在浏览器本地（localStorage），不上传任何服务器。

## 使用

```bash
npm install
npm run dev      # 本地开发
npm run build    # 生产构建到 dist/
```

## 功能

- **导入清单**：在左侧粘贴每行 `名称@版本 许可证`，或上传 `.txt / .json / .csv / .lock` 文件（支持 package.json、package-lock.json、license-checker 输出及 `[{name, version, license}]` 数组）；也可直接拖放文件。缺省许可证的条目按“未知”处理；同名同版本自动去重；支持 `@scope/pkg@版本` 作用域包名。
- **自动汇总**：顶部实时统计 已分析依赖 / 兼容通过 / 需要复核 / 高风险冲突。
- **判定规则**：
  - ✅ MIT、Apache-2.0、BSD-3-Clause → 兼容通过（保留声明即可分发）
  - ⛔ GPL-3.0 → 高风险冲突（强 Copyleft）
  - ⚠️ Proprietary、未知许可证及其余非白名单许可证 → 需要法务复核
- **查看依据**：点击任意条目，在底部展开该许可证的具体判定理由，可在面板内直接删除条目。
- **搜索 + 筛选**：关键字（名称/版本/许可证）与结论筛选同时作用于结果列表，并显示“显示 N / 共 M 条”。
- **手动补录**：填写名称/版本/许可证后立即加入列表与统计，条目标记“手动补录”，重复的同名同版本会被拒绝。
- **持久化**：所有条目写入 localStorage，关掉页面再打开仍在；点击“重置示例”恢复内置示例清单。
- **导出 Markdown**：导出覆盖当前全部条目的报告（不受搜索/筛选影响），含汇总、明细表、高风险冲突依据与待复核项。
